## Finding (not a factory defect)

The second attempt exited 73 at `:app:mergeDebugResources` because
`android/app/src/main/res/values/` contained stray hash-named files
(`values/a192ecfc`, `values-night/1f77ec02`) holding `styles.xml` content — a
file name without `.xml` is rejected by AAPT2. These were debris from the first
attempt being killed mid-copy, not something the generator emits: a clean
regeneration produced only `styles.xml` in both directories and built the APK.
Worth knowing for the factory's support runbook: an interrupted generation can
leave a resource directory that fails the APK gate on the *next* run, and the fix
is to delete the app directory rather than to retry `--regenerate` in place.
