# archive — historical batch records

Everything here is a **record of a past session**, not current truth. Audits,
fix batches, white-label rounds, implementation prompts and readiness reports
accumulated between August and November 2026 and were moved out of the repository
root so the root reads as a project rather than a session log.

Rules for this folder:

- Nothing here is cited as current behaviour. Where an archived document and the
  code disagree, the code wins.
- Paths inside these files are **as of their date**. Some point at the
  pre-archive root layout (for example `WHITE_LABEL_p32_golden_gates.md` now lives
  here) and some at `docs/` files that have since moved or been superseded.
- A finding is only a finding if a live document carries it. Live claims live in
  `../HANDOFF.md`, `../ROADMAP.md`, `../docs/DECISIONS.md`,
  `../docs/INCIDENT_LEDGER.md` and `../docs/DEEP-DIVE.md`.
- Do not add to this folder. New work goes to `docs/` or a checkpoint.

- The historical tool folders (`../tool_audit/`, `../tool_uilib/`, `../tool_fix/`, `../tool_archive/`, `../_prompt_originals/`) are frozen snapshots too. Their internal paths are as of their date and are not repaired when something moves.
